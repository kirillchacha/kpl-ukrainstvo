# KPL-Ukrainstvo - Distance Learning School Website

A fully responsive multi-page website for KPL-Ukrainstvo, a "Дистанційна школа" (distance learning school) offering online education, featuring multiple study formats, video lessons, blog content, and enrollment forms - built in Ukrainian.

## 🔗 Live Demo

[https://kirillchacha.github.io/kpl-ukrainstvo/](https://kirillchacha.github.io/kpl-ukrainstvo/)

## ✨ Features

- **Hero section** - introduction to the distance learning platform
- **About School page** - background and educational approach
- **Four study formats** - Extern, Basic, Deepened, and Graduating, each with a dedicated page
- **Video lessons** - subject-based video lesson access
- **Free trial lesson registration** - modal form for booking a trial class
- **Consultation requests** - dedicated form for prospective student inquiries
- **Blog section** - multiple blog layout variants (standard, blank, no-date, no-messages, pattern)
- **Interactive modals** - six popups covering enrollment, video lesson access, consultations, trial registration, and success confirmation
- **Contact page** - dedicated contact information and form
- **Login option** - access point for enrolled students
- **Custom 404 page** - branded error page
- **Responsive navigation** - header linking Home, About School, Learning Forms (with subcategories), Blog, Contacts, and Login
- **Fully responsive design** - optimized layout for desktop, tablet, and mobile

## 🛠️ Tech Stack

- **HTML5** - semantic markup for structure and SEO
- **CSS** - custom styling for layout, typography, and responsiveness
- **JavaScript** - modal logic and dynamic UI interactivity
- **Sendmail integration** - backend script support for consultation/trial forms
- **Custom fonts & icons** - for a polished, on-brand visual style
